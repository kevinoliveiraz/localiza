# Distribuição do projeto

O repositório reúne a prévia atual do frontend, com busca, informações fictícias, tabelas de campos livres, administração, simulação de perfis, modo claro/escuro e vídeo na tela inicial sem margens externas. Mapa e 3D permanecem com a implementação anterior.

Os arquivos necessários de Three.js e sua licença acompanham o código. As dependências de desenvolvimento podem ser instaladas com `npm install`. Os motores opcionais de análise 3D são preparados separadamente; consulte o README e o documento 08.

Não são versionados dados de contas ou organizações, arquivos `.env`, ferramentas instaladas, dependências em `node_modules`, resultados de validação ou preferências do editor. As referências visuais e os recortes históricos não usados pela interface atual também permanecem fora da distribuição. Esses arquivos continuam no computador do responsável.

A licença do código é MIT, conforme `LICENSE`. Componentes externos mantêm as licenças registradas em `THIRD_PARTY.md`.
